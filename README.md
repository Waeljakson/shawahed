# منصة الشواهد والأدلة — متوسطة وثانوية مشكاة الشعلة الأهلية

منصة لرفع شواهد التقويم المدرسي ومتابعتها، وفق **الدليل الاسترشادي لأخصائي التقويم المدرسي** الصادر عن هيئة تقويم التعليم والتدريب (52 فقرة، و149 وثيقة مطلوبة).

- **الواجهة:** صفحات ثابتة على GitHub Pages (مجلد `site/`).
- **قاعدة البيانات وتسجيل الدخول والملفات:** Appwrite Cloud (الخطة المجانية).
- **الإعداد التلقائي:** GitHub Actions يُنشئ الجداول والصلاحيات ومساحة الملفات وحساب المدير ووظيفة إدارة المستخدمين (مجلد `setup/`).

> قبل ربط قاعدة البيانات تعمل المنصة في **وضع تجريبي**، وتُحفظ البيانات في المتصفح فقط.

---

## خطوات الإعداد (مرة واحدة فقط)

### 1) إنشاء مشروع Appwrite
1. ادخل إلى https://cloud.appwrite.io وسجّل بحساب GitHub أو بالإيميل.
2. أنشئ مشروعًا جديدًا (**Create project**) باسم `shawahed`، واختر المنطقة الأقرب (Frankfurt مثلًا).
3. من صفحة المشروع (**Overview** أو **Settings**) انسخ:
   - **Project ID**
   - **API Endpoint** (مثل `https://fra.cloud.appwrite.io/v1`)
4. أضف المنصة كتطبيق ويب: **Add platform** ← **Web**، وفي **Hostname** اكتب:
   `waeljakson.github.io`
5. أنشئ مفتاح API: **Overview** ← **API keys** (أو **Integrations**) ← **Create API key**:
   - الاسم: `github-setup`
   - الصلاحيات (Scopes): اختر **الكل (Select all)**
   - الانتهاء: **Never**
   - انسخ قيمة المفتاح (Secret).

### 2) إضافة الأسرار في GitHub
في الريبو: **Settings** ← **Secrets and variables** ← **Actions** ← **New repository secret**، وأضف:

| الاسم | القيمة |
|---|---|
| `APPWRITE_API_KEY` | مفتاح API من الخطوة السابقة |
| `ADMIN_USERNAME` | اسم دخول المدير بالإنجليزية، مثل `admin` |
| `ADMIN_PASSWORD` | كلمة مرور المدير (8 أحرف فأكثر) |
| `ADMIN_NAME` | اسم المدير الظاهر، مثل `صلاح الصبحي` |

### 3) تفعيل GitHub Pages
في الريبو: **Settings** ← **Pages** ← **Source**: اختر **GitHub Actions**.

### 4) وضع بيانات المشروع
عدّل الملف `site/config.json` واكتب فيه `endpoint` و`projectId`. بمجرد الحفظ في فرع `main`:
- يشتغل **«إعداد قاعدة البيانات»** تلقائيًا (من تبويب **Actions**)، فيُنشئ الجداول ويضيف الفقرات ويُنشئ حساب المدير.
- يشتغل **«نشر المنصة»**، وتصبح المنصة على: `https://waeljakson.github.io/shawahed/`

## الصلاحيات
| الصلاحية | ما يستطيعه |
|---|---|
| مدير النظام | كل شيء، وإدارة المستخدمين والإعدادات |
| مراجع (لجنة التميز) | الرفع في كل الفقرات، واعتماد الوثائق أو طلب تعديلها |
| مسؤول رفع الشواهد | الرفع والتقييم الذاتي في الفقرات المسندة لجهته فقط |
| مطّلع فقط | مشاهدة الإحصائيات والملفات |

الحسابات تُنشأ من داخل المنصة (صفحة **المستخدمون**)، ولا يستطيع أي شخص إنشاء حساب بنفسه والوصول للبيانات.

## ملاحظات مهمة
- **التوقف بعد أسبوع:** مشاريع Appwrite المجانية تتوقف مؤقتًا إذا لم تُستخدم أسبوعًا كاملًا. لإعادة تشغيلها ادخل لوحة Appwrite واضغط **Restore/Resume**.
- **المساحة:** الخطة المجانية فيها 2 جيجابايت للملفات، والحد الأقصى للملف الواحد 30 ميجابايت.
- **نسيت كلمة مرور المدير:** حدّث `ADMIN_PASSWORD` في Secrets، ثم من **Actions** ← «إعداد قاعدة البيانات» ← **Run workflow**، وفعّل خيار إعادة تعيين كلمة المرور.
- **إعادة تشغيل الإعداد آمنة:** السكربت يضيف الناقص فقط، ولا يمسح أي بيانات.

## هيكل المشروع
```
site/                  الواجهة (GitHub Pages)
  config.json          بيانات الاتصال بـ Appwrite
  js/app.js            الصفحات والإحصائيات
  js/api.js            الاتصال بقاعدة البيانات (+ الوضع التجريبي)
  data/seed.json       فقرات الدليل
setup/                 سكربت الإعداد
  schema.mjs           الجداول والصلاحيات
  setup.mjs            الإنشاء والتحديث
  function/            وظيفة إدارة المستخدمين
.github/workflows/     النشر والإعداد التلقائي
```
